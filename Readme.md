# Cyberpunk Roguelike
This is in-process tile-based roguelike in a cyberpunk setting. Already implemented:
- basic tile based movement
- basic world generation with noise pattern and Voronoi diagrams

## Player Guide
### Actions
<pre>
- Movement (Player, Cursor):    WASD, Arrow keys, Numpad (also diagonal movement)
- Zoom:                         z (in), Z (out)
- Switch to continent map:      c
- Switch to region map:         m
- Switch to local:              l
- Use cursor:                   x (start/exit)
</pre>
